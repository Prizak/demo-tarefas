# Lista de Tarefas (demo)

Demo estática e fictícia de uma lista de tarefas, feita só com HTML, CSS e JavaScript puros. Sem framework, sem build, sem dependências.

Permite adicionar, concluir e remover tarefas. Os dados ficam apenas em uma variável do JavaScript: ao recarregar a página, a lista volta a ficar vazia.

## Como abrir

Abra o arquivo `index.html` no navegador (duplo clique ou "Abrir com...").
